# Master prompt — plan and implement an advanced feature

---

Product expansion requested: **[FEATURE / R2+ TICKET]**. Read the complete relevant product, UX, architecture, data, AI/integration, security and roadmap specs; inspect current repo and status. Determine if the prerequisite milestone is truly complete. Draft a short implementation design covering user value, mobile flow, entities/migrations, APIs, permissions, failure states, provider requirements/cost, deterministic invariants, tests, feature flag and migration/reversal strategy. Distinguish uncertain assumptions and seek explicit approval for scope changes or paid/external commitments. If implementation already explicitly authorized, proceed with approved bounded scope; otherwise stop after plan.

Never add direct marketplace booking, payments, e-signature, autonomous message delivery, data sharing, unrestricted AI tools or new provider credentials without explicit authorization. Provider failures must leave core planning intact. AI suggestions typed, source-evidenced, reviewable and applied via normal services. Advanced seating cannot violate hard constraints; 3D/AI visuals labeled concept. Update decisions/backlog/status with actual changes, run relevant tests, report blockers and keep scope bounded.
