# GAP_BACKLOG.md

Dependency-ordered remediation plan. **No implementation was done.** Severity: **S0** data-integrity/security break · **S1** fails a core promise of the connected model · **S2** significant capability gap · **S3** polish/hardening. Effort: XS <½d · S 1–2d · M 3–7d · L 2–4w · XL >1m. “Test IDs” are the repo's own names or the PDF §8 test (kit AT-* unavailable). Every fix must follow the repo's existing pattern: forward-only migration, composite `(wedding_id,…)` FKs, RLS select + RPC-only writes, version check, idempotency key, field-name-only audit, integration tests for races and tenancy (`AGENTS.md`, `docs/12-TESTING.md`).

**No S0 finding.** Nothing observed breaks tenant isolation, money integrity or seat uniqueness.
